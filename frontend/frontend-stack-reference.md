# Frontend Stack Reference

The canonical stack for the Oraclous frontend. Every choice listed here is locked unless an ADR retires it.

| Concern | Choice |
| --- | --- |
| Framework | React 18.3 |
| Language | TypeScript 5.5 |
| Build tool | Vite 5.4 |
| Router | react-router-dom 6.26 |
| Server state | @tanstack/react-query 5.56 |
| Client state | zustand 5.0 |
| Forms | react-hook-form 7.53 |
| Validation | zod 3.23 |
| UI primitives | Radix + shadcn/ui |
| Styling | Tailwind 3.4 |
| Icons | lucide-react |
| Graph/canvas | @xyflow/react 12.8 |
| Unit tests | Vitest |
| E2E tests | Playwright |

## Out of scope (do not add)

- Redux, MobX, Recoil, Jotai
- Formik, Final Form
- styled-components, Emotion, vanilla-extract
- Material UI, Ant Design, Chakra
