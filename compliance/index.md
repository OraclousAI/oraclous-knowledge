# 06. Compliance

The compliance posture for cloud-hosted deployment of Oraclous.

Self-hosted customers operate their own compliance posture; the platform exposes the substrate primitives (audit logs, isolation guarantees, encryption) they need to satisfy their auditors.

## Posture summary

- **Target certifications**: ISO 27001 and SOC 2 Type II
- **In-scope deployment**: cloud-hosted only
- **Foundational principle**: architectural controls preferred over policy controls; provenance is evidence
- **Same-code guarantee**: self-hosted and cloud-hosted run the same enforcement code
