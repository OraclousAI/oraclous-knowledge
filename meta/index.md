# 08. Meta

Documentation about the documentation. This hub captures how the knowledge base is structured, written, maintained, and changed; it also captures the integration boundaries between Confluence, Jira, GitHub, Claude Code, and the various model providers the platform depends on.

## What's here

* [Documentation Conventions](https://oraclous.atlassian.net/wiki/spaces/OP/pages/884820) — writing style, page anatomy, status conventions
* [Glossary](https://oraclous.atlassian.net/wiki/spaces/OP/pages/720981) — canonical definitions of terms used across the knowledge base
* [Change Log](https://oraclous.atlassian.net/wiki/spaces/OP/pages/557174) — material structural changes to the knowledge base over time
* [Contributing to Documentation](https://oraclous.atlassian.net/wiki/spaces/OP/pages/688383) — how to add, edit, and restructure pages
* [Tooling and Integration Map](https://oraclous.atlassian.net/wiki/spaces/OP/pages/164042) — sources of truth, Atlassian / GitHub / Claude Code setup, MCP connections

## Why this hub exists

The Oraclous knowledge base spans architecture, engineering, operations, compliance, and customer trust. Without explicit conventions, it would drift: definitions would diverge, structure would calcify around accidents, and contributors (human and agent) would have to reverse-engineer what we mean each time they touched the docs.

This hub fixes that. Every contributor reads at least Documentation Conventions and the Glossary before writing into the space.

## Who reads this hub

* **New contributors (human)** — start here before writing anywhere else
* **The docs-writer agent** — Documentation Conventions and Glossary are loaded as standing context
* **Reza** — for periodic review of how the knowledge base is evolving
* **Auditors** — Tooling and Integration Map shows how engineering process artifacts integrate

## Relationship to ADRs

ADRs (under 02. ADRs) record _architectural_ decisions. The Meta hub records _documentation_ decisions — how the knowledge base itself works. The two are kept separate because their cadence and authority differ.
