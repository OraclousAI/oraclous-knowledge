# R0.5 — Phase 0.5: Organisation tenancy and metering substrate

| Release ID | R0.5 |
| --- | --- |
| Status | Done |
| Window | Weeks 3-4 (parallel with R1) |
| Owner | tech-lead |

## Goal

Add `organisation_id` scoping to every substrate storage primitive and implement substrate-level metering of resource consumption.

## Deliverables

- [x] `organisation_id` on every storage primitive — Neo4j, Postgres, Redis, search indexes
- [x] Every query path enforces `organisation_id` from authenticated context (never request body)
- [x] Multi-tenant components extended with outer organisation-scoping layer
- [x] Isolation test suite extended — substrate-level gate with real Neo4j/Postgres/Redis
- [x] Metering subsystem live — append-only, tamper-evident usage-event stream
- [x] Usage reporting API (substrate-level aggregation primitive)
- [x] Migration script for existing deployments (idempotent organisation backfill)
