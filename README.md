# Oraclous Knowledge Base

This repository is the **canonical** source of truth for Oraclous engineering knowledge.

> **Confluence is the mirror.** Changes should be made here and synced to Confluence, not the reverse.

## Structure
- `architecture/` — Platform architecture, OHM Spec, Governance Taxonomy, Threat Catalogue
- `adr/` — Architecture Decision Records
- `engineering/` — Agent Skills Catalogue and persona definitions
- `services-reference/` — Service reference documentation
- `operations/` — Operational runbooks and procedures
- `compliance/` — Compliance documentation
- `frontend/` — Frontend documentation
- `meta/` — Meta documentation about this knowledge base
- `releases/` — Release planning and notes
- `flows/` — Engineering workflows and flows
- `contracts/` — Interface contracts
- `_mirror/` — Sync metadata (confluence-map.yaml)
